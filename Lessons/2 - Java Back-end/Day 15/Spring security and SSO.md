### Repository


This lesson starts with a new `JavaOidc` resource-server project and isolates one mechanism: authentication. Keycloak runs as a Devbox service, its realm is configured in the Keycloak dashboard, and Spring Security checks access before a controller method runs.

> [!important] Starting point
> Build only the project shown in this lesson. Do not copy code from another application. `AuthTestController` is the only controller and contains one public endpoint and one protected endpoint.
