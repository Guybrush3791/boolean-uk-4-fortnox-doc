## RESTful APIs
**RESTful APIs** are application programming interfaces that follow **REST (Representational State Transfer)** principles, providing a standard way for software systems to communicate over the internet. ^[https://aws.amazon.com/what-is/restful-api/]

## OpenAPI
The **OpenAPI Specification** (formerly Swagger) is a standard documentation format that describes RESTful APIs in a structured, machine-readable way. ^[https://dev.to/sacode/designing-restful-apis-with-openapi-a-top-down-approach-b33]
