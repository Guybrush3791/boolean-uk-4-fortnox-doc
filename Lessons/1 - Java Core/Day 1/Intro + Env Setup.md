Welcome to the *Boolean UK / Fortnox Java Full-Stack Academy 2026*. This first day is a **soft start**: no code to submit, no graded work. The goal is to make sure your machine is ready, your accounts are wired up, and you know how a Java project is built and run, so from *Day 02* onwards you can focus on the actual programming.

## Documentation
You should now have Obsidian installed and the public academy documentation open as a vault. The vault contains a few different parts, but you will normally navigate from the [[Accademy Home Page]] rather than browsing its folders directly.

The **Accademy Home Page** is the course index. It will grow as material is released, day by day. Each row links to a lesson page, which brings together the resources for that day. Depending on the lesson, these resources may include theory, live coding and an afternoon exercise, each held in one or more linked repositories.

The `Lessons` folder contains the lesson pages and supporting explanations, while the `Repository` folder contains the linked teaching and exercise repositories. You can explore these folders if needed, but the index is the clearest way to find the material in the intended order.
