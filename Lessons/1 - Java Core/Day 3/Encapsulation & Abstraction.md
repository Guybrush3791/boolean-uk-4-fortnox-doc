## Encapsulation
**Encapsulation** bundles data and the methods that operate on it inside a class. It hides internal implementation details and controls access to that data through well-defined methods.

![[Encapsulation|600]]

## Abstraction
**Abstraction** hides internal implementation details while exposing only essential functionality. It focuses on what an object does rather than how it does it.

![[Abstraction|1200]]
