## Polymorphism
**Polymorphism** means "many forms" and allows objects from different classes to be treated through a common type. A single interface can therefore represent several underlying forms.

![[Polymorphism|1000]]

## Inheritance
**Inheritance** allows a class to acquire properties and behaviours from another class. The inheriting class is the **child class** or **subclass**, while the source is the **parent class** or **superclass**.

![[Inheritance|600]]
